# Sécurité offensive

[Ciberseguridad](/?c=cybersecurite) cubre los fallos de aplicaciones y web, y cómo protegerse de ellos. Esta categoría cambia de ángulo: entender cómo se ataca realmente un sistema al nivel más bajo (memoria, binario, sistema operativo), para formar la mirada de un atacante en lugar de la de un defensor. Ambas se complementan: se protege mejor lo que se sabe atacar.

> **Marco legal:** todo lo que sigue solo se aplica en un entorno autorizado (un reto de tipo [CTF](/?c=securite&s=securite-offensive&p=ctf-capture-the-flag), una máquina de laboratorio dedicada, un sistema que posees o para el que tienes un mandato escrito). Aquí se aplica el mismo recordatorio ya planteado para el [pentest](/?c=cybersecurite&p=tests-et-audit-de-securite): sin autorización explícita, la misma acción se vuelve ilegal, incluso sin intención de causar daño.
