# Descripción

Esta sección cubre los distintos lenguajes del sitio, cada uno con su propia sintaxis: los lenguajes de programación generalistas (**C**, **C++**, **PHP**, **Python**, **JavaScript**, **OCaml**), los lenguajes de marcado que describen una página web en lugar de un comportamiento (**HTML**, **CSS**), los lenguajes de línea de comandos de una terminal (**Bash**, **Zsh**, **PowerShell**), y los lenguajes de propósito específico diseñados para un problema concreto en lugar de hacerlo todo (**Domain-specific Languages (DSL)**, ej. SQL, regex).
