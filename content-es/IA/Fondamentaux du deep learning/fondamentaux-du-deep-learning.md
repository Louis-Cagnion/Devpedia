# Fondamentaux du deep learning

Esta parte cubre los componentes comunes a todo modelo de **deep learning**, antes de que se especialice para una tarea precisa (texto, imagen, reconocimiento de caracteres...): cómo calcula una neurona, cómo aprende una red a partir de datos, y las grandes familias de arquitecturas que organizan esas neuronas (CNN, RNN, Transformers).
