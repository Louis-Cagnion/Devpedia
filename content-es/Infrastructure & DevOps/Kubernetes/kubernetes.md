# Kubernetes

[Docker](/?c=infrastructure-devops&s=docker&p=docker) sabe hacer funcionar un contenedor; Kubernetes sabe hacer funcionar **toda una flota** de contenedores mientras las máquinas fallan, el tráfico varía y nuevas versiones se entregan continuamente. Se describe lo que se quiere ver funcionando, y Kubernetes hace que la realidad corresponda a esa descripción, de forma continua.
