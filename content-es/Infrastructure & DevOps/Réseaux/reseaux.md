# Réseaux

Esta categoría cubre el funcionamiento de una red informática, desde el direccionamiento de una máquina hasta la comunicación entre programas mediante sockets. Se sitúa por debajo del nivel de aplicación ya cubierto en otro lugar (por ejemplo, [Los intercambios de datos: API y HTTP](/?c=infrastructure&p=api-et-http), que supone una conexión de red ya establecida): aquí se explica cómo esa conexión existe y se construye, desde el cable hasta el programa.
