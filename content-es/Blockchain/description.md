# Description

Esta categoría cubre la blockchain: cómo una red de ordenadores que no confían entre sí puede aun así ponerse de acuerdo sobre un historial común, sin un banco ni un servidor central que arbitre. Parte de los conceptos fundamentales (bloque, hash, consenso, smart contract) antes de abordar los lenguajes y redes usados para construir sobre ellos.
