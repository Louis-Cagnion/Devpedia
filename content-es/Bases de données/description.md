# Descripción

Esta sección cubre la forma en que se organizan los datos una vez que se supera la tabla única vista en [SQL](/?c=domain-specific-languages-dsl&p=sql): cómo estructurar varias tablas entre sí para analizar grandes volúmenes de histórico (informes, paneles de control) en lugar de hacer funcionar una aplicación en el día a día, y el vocabulario de las tablas que se encuentra en un almacén de datos real.

Se distingue de [Data Science](/?c=data-science): esta última cubre las herramientas para explotar datos ya disponibles ([pandas](/?c=data-science&p=pandas), [NumPy](/?c=data-science&p=numpy)...), esta cubre cómo esos datos están estructurados y organizados previamente.
