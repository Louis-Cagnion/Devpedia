# PHP

PHP se considera un lenguaje de programación de **alto nivel**, ya que oculta gran parte de los detalles técnicos relacionados con el hardware y la gestión de la memoria. A diferencia de los lenguajes de **bajo nivel** como el C, que exigen al desarrollador gestionar manualmente la memoria y las direcciones, PHP automatiza estos aspectos gracias a un recolector de basura (*garbage collector*), lo que permite centrarse en la lógica de la aplicación.

Entre los conceptos esenciales que se manejan en PHP, destacan, entre otros:

- Las variables y el tipado dinámico
- Las tablas (indexadas y asociativas)
- La programación orientada a objetos (clases, interfaces, herencia)
- Interacción con las solicitudes HTTP (GET, POST, sesiones, cookies)
- Conexión y gestión de bases de datos (a través de PDO o MySQLi)

Aprender PHP permite comprender mejor cómo un servidor web procesa una solicitud, genera una respuesta e interactúa con un cliente (navegador). Ayuda a visualizar cómo circulan los datos entre el cliente, el servidor y la base de datos, y cómo se interpreta el código durante la ejecución.

Gracias a su sencillez y a su integración nativa con la web, PHP se utiliza ampliamente para el desarrollo de sitios web dinámicos, aplicaciones web, sistemas de gestión de contenidos (CMS) y API.

Aprender PHP también constituye una base excelente para comprender el funcionamiento de las aplicaciones web del lado del servidor, ya que muchos marcos de trabajo (Laravel, Symfony) y sistemas de gestión de contenidos (WordPress, Drupal) se basan en este lenguaje.
