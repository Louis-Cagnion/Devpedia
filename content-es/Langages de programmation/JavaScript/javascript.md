# JavaScript

JavaScript se considera un lenguaje de programación de **alto nivel**, ya que oculta gran parte de los detalles técnicos relacionados con el hardware y la gestión de la memoria. A diferencia de los lenguajes de **bajo nivel** como el C, que exigen al desarrollador gestionar manualmente la memoria y las direcciones, JavaScript automatiza estos aspectos gracias a un recolector de basura (*garbage collector*), lo que permite centrarse en la lógica de la aplicación.

Entre los conceptos fundamentales que se manejan en JavaScript se encuentran, entre otros:

- Las variables y el tipado dinámico
- Las tablas y los objetos
- La programación orientada a objetos (clases, prototipos, herencia)
- Manipulación del DOM (HTML, CSS) para crear interfaces interactivas
- Gestión de eventos (clics, formularios, teclado)
- La programación asíncrona (callbacks, promesas, async/await) y las solicitudes de red (fetch, AJAX)

Aprender JavaScript permite comprender mejor cómo una página web se vuelve interactiva, cómo el navegador interpreta y ejecuta el código, y cómo circulan los datos entre el cliente y el servidor durante los intercambios asíncronos.

Gracias a su versatilidad, JavaScript se utiliza tanto en el lado del cliente (navegador) como en el lado del servidor (a través de Node.js), lo que lo convierte en un lenguaje fundamental para el desarrollo web moderno.

Aprender JavaScript también constituye una base excelente para comprender el funcionamiento de las aplicaciones web del lado del cliente, ya que muchos marcos de trabajo (React, Vue, Angular) y entornos (Node.js, Express) se basan en este lenguaje.
