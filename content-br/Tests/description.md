# Description

Esta categoria cobre os testes de software: como verificar se um programa realmente faz o que deveria fazer, antes que um usuário descubra da pior forma. Ela parte do vocabulário normalizado da disciplina antes de abordar os diferentes tipos de teste, sua organização e as ferramentas que os mantêm sustentáveis.

O capítulo [testes e auditoria de segurança](/?c=securite&s=cybersecurite&p=tests-et-audit-de-securite) cobre a busca por falhas de segurança, um objetivo diferente do dos testes cobertos aqui (verificar se o programa funciona como esperado).
