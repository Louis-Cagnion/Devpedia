# Description

Para lembrar, [o terminal exibe e transmite o que você digita, o shell interpreta e o executa de fato](/?c=bases-de-l-informatique&p=le-terminal). Vários shells existem conforme o sistema e o uso: o Bash domina no Linux/macOS, o PowerShell no Windows (e além disso, ele também roda no Linux/macOS desde o PowerShell Core).
