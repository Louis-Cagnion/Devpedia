# Configuration de LLMs

Esta parte cobre a forma de personalizar e automatizar o comportamento de um LLM ou de um agente LLM, uma vez que já se sabe o que é um agente ([loop reflexão/ação](/?c=ia&s=nlp-llm&p=agents)) e como é um produto construído em torno dele ([assistente agêntico em terminal](/?c=ia&s=applications-llm&p=assistant-agentique-terminal)): como fazê-lo reagir de forma confiável em um momento preciso de seu funcionamento, sem depender unicamente de uma instrução no prompt.
