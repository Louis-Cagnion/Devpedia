# Description

Esta seção cobre a forma como se organizam os dados quando se ultrapassa a tabela única vista em [SQL](/?c=domain-specific-languages-dsl&p=sql): como estruturar várias tabelas entre si para analisar grandes volumes de histórico (relatórios, dashboards) em vez de fazer rodar uma aplicação no dia a dia, e o vocabulário das tabelas que se encontra em um data warehouse real.

Ela se distingue de [Data Science](/?c=data-science): esta última cobre as ferramentas para explorar dados já disponíveis ([pandas](/?c=data-science&p=pandas), [NumPy](/?c=data-science&p=numpy)...), enquanto esta cobre como esses dados são estruturados e organizados a montante.
