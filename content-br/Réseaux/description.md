# Description

Esta categoria cobre o funcionamento de uma rede de computadores, desde o endereçamento de uma máquina até a comunicação entre programas via sockets. Ela se situa abaixo do nível de aplicação já coberto em outro lugar (ex.: [As trocas de dados: API e HTTP](/?c=infrastructure&p=api-et-http), que pressupõe uma conexão de rede já estabelecida): aqui, explica-se como essa conexão existe e se constrói, do cabo até o programa.
