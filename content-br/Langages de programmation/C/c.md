# C

A linguagem C é considerada uma linguagem de programação de **baixo nível**, uma vez que oferece acesso direto a muitos mecanismos fundamentais da máquina. Ao contrário das linguagens de **nível superior**, que ocultam grande parte desses detalhes, a linguagem C permite ao programador controlar com precisão o comportamento do programa e a sua utilização dos recursos do sistema.

Entre os conceitos essenciais utilizados em C, destacam-se, nomeadamente:

- Gestão da memória
- Os tipos de dados e a sua representação na memória
- Os ponteiros e os endereços de memória
- A alocação e a libertação de memória dinâmica
- Interações com o sistema operativo e o hardware

A aprendizagem da linguagem C permite compreender melhor o que acontece quando um programa é executado pelo computador. Ajuda a visualizar como os dados são armazenados na memória, como as variáveis são representadas e como o processador executa as instruções geradas a partir do código-fonte.

Graças a esta proximidade com o hardware, a linguagem C é amplamente utilizada no desenvolvimento de sistemas operativos, controladores de hardware, sistemas incorporados e software que exigem elevado desempenho.

Estudar o C constitui também uma excelente base para compreender o funcionamento interno de muitas outras linguagens de programação, uma vez que muitas delas se baseiam em conceitos herdados do C ou interagem com bibliotecas escritas nessa linguagem.
