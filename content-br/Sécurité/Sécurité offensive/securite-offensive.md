# Sécurité offensive

[Cibersegurança](/?c=cybersecurite) cobre as falhas de aplicações e falhas web, e como se proteger delas. Esta categoria muda de ângulo: entender como um sistema é realmente atacado no nível mais baixo (memória, binário, sistema operacional), para formar o olhar de um atacante em vez do de um defensor. Os dois se complementam: protege-se melhor aquilo que se sabe atacar.

> **Marco legal:** tudo o que segue só se aplica em um ambiente autorizado (desafio do tipo [CTF](/?c=securite&s=securite-offensive&p=ctf-capture-the-flag), máquina de laboratório dedicada, sistema que você possui ou para o qual tem um mandato por escrito). O mesmo alerta já feito para o [pentest](/?c=cybersecurite&p=tests-et-audit-de-securite) se aplica aqui: sem autorização explícita, a mesma ação se torna ilegal, mesmo sem intenção de causar dano.
