# Description

Esta seção cobre as diferentes linguagens do site, cada uma com sua própria sintaxe: as linguagens de programação generalistas (**C**, **C++**, **PHP**, **Python**, **JavaScript**, **OCaml**), as linguagens de marcação que descrevem uma página web em vez de um comportamento (**HTML**, **CSS**), as linguagens de comando de um terminal (**Bash**, **Zsh**, **PowerShell**), e as linguagens de propósito específico projetadas para um problema preciso em vez de fazer tudo (**Domain-specific Languages (DSL)**, ex. SQL, regex).
