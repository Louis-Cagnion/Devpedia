# Description

Esta seção cobre as diferentes linguagens do site, cada uma com sua própria sintaxe: as linguagens de programação generalistas (**[C](/?c=langages&s=c&p=c)**, **[C++](/?c=langages&s=cpp&p=cpp)**, **[PHP](/?c=langages&s=php&p=php)**, **[Python](/?c=langages&s=python&p=python)**, **[JavaScript](/?c=langages&s=javascript&p=javascript)**, **[OCaml](/?c=langages&s=ocaml&p=ocaml)**), as linguagens de marcação que descrevem uma página web em vez de um comportamento (**[HTML](/?c=langages&s=html&p=html)**, **[CSS](/?c=langages&s=css&p=css)**), as linguagens de comando de um terminal (**[Bash](/?c=langages&s=bash&p=bash)**, **[Zsh](/?c=langages&s=zsh&p=zsh)**, **[PowerShell](/?c=langages&s=powershell&p=powershell)**), e as linguagens de propósito específico projetadas para um problema preciso em vez de fazer tudo (**[Domain-specific Languages (DSL)](/?c=langages&s=domain-specific-languages-dsl&p=domain-specific-languages-dsl)**, ex. [SQL](/?c=langages&s=domain-specific-languages-dsl&p=sql), [regex](/?c=langages&s=domain-specific-languages-dsl&p=regex)).
