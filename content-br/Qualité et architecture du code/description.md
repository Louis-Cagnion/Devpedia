# Description

Um programa que produz o resultado correto não é necessariamente um programa fácil de evoluir. Esta seção reúne princípios de qualidade e arquitetura que não dependem de uma linguagem específica: eles se aplicam tanto a um script Python quanto a um projeto JavaScript ou uma base de código C.

O fio condutor é a **manutenibilidade**: um código que se entende sem esforço, que não repete a mesma informação em vários lugares, e onde uma mudança permanece localizada em vez de se propagar em cascata. Esses princípios não são regras estéticas: cada um evita uma categoria precisa de bug ou de regressão, ilustrada por um caso concreto.
