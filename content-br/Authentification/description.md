# Descrição

Esta categoria cobre a autenticação de ponta a ponta, independentemente da linguagem ou do framework utilizado: como provar a própria identidade (**Fundamentos**: senhas, fatores de autenticação), como um servidor lembra que um usuário permanece conectado de uma requisição HTTP para outra (**Sessões e tokens**: cookies, JWT), como delegar essa identidade a terceiros em vez de gerenciá-la sozinho (**Delegação e federação de identidade**: OAuth 2.0, OpenID Connect, SSO com o Okta como exemplo concreto), e como reduzir o risco de que um único segredo comprometa toda uma conta (**Reforçar a autenticação**: autenticação multifator).
