# Os OKR

Todos os capítulos anteriores desta subcategoria tratam da organização do **trabalho**: como dividi-lo, estimá-lo, acompanhá-lo. Resta uma pergunta sem resposta: como garantir que esse trabalho realmente serve a um propósito maior? Os **OKR** (*Objectives and Key Results*) respondem a essa pergunta, ligando explicitamente o trabalho do dia a dia a objetivos de nível mais alto.

## Duas partes, dois papéis diferentes

Um OKR sempre se compõe de dois elementos distintos, cada um com um papel preciso:

| Elemento | Papel | Característica |
|---|---|---|
| **Objective** (objetivo) | Aonde queremos chegar | Qualitativo, ambicioso, formulado em uma frase inspiradora |
| **Key Results** (resultados-chave) | Como saberemos que chegamos | Quantitativos, mensuráveis, de 2 a 5 por objetivo |

```text
Objective: Tornar-se a referência de suporte ao cliente no nosso setor

Key Results:
  KR1: Elevar a satisfação do cliente de 72% para 90%
  KR2: Reduzir o tempo de primeira resposta de 4h para 30 minutos
  KR3: Atingir uma taxa de resolução no primeiro contato de 80%
```

O objetivo sozinho ("tornar-se a referência de suporte") não diz se foi alcançado ou não; os resultados-chave, por sua vez, são verificáveis sem ambiguidade em uma data determinada.

> **Cilada:** confundir um Key Result com uma tarefa a fazer ("Implantar um novo software de suporte"). Uma tarefa descreve uma ação, um Key Result descreve um resultado mensurável; a mesma intenção se reformula como Key Result através de seu efeito esperado ("Reduzir o tempo de primeira resposta para 30 minutos"), tornando-se a própria tarefa um dos meios, entre outros, de chegar lá.
>
> **Boa prática:** sempre verificar se um Key Result é formulado como uma medida verificável (um número, uma porcentagem, um limiar), nunca como uma ação a marcar.

## Conectar os OKR ao trabalho diário

A ligação com os [backlogs e user stories](/?c=gestion-de-projet-et-organisation&s=gestion-de-projet&p=backlog-et-user-stories) já vistos acontece naturalmente: cada Key Result inspira as user stories que contribuem concretamente para alcançá-lo, sem que o OKR em si desça ao nível do detalhe de implementação.

```text
Key Result: Reduzir o tempo de primeira resposta de 4h para 30 minutos
    │
    ├── User story: Adicionar um sistema de resposta automática
    │   para perguntas frequentes
    ├── User story: Notificar a equipe de suporte em tempo real
    │   sobre um novo ticket
    └── User story: Priorizar automaticamente os tickets urgentes
```

## Ambicioso em vez de garantido

Ao contrário de um objetivo clássico de desempenho individual, um OKR é deliberadamente ambicioso: uma taxa de alcance almejada em torno de 60-70% costuma ser considerada saudável, enquanto um OKR sistematicamente alcançado em 100% sugere uma meta fixada baixa demais para ser realmente estimulante.

> **Cilada:** usar a taxa de alcance de um OKR como medida de desempenho individual ou de avaliação, o que empurra mecanicamente para fixar metas fáceis em vez de ambiciosas, para evitar uma nota ruim.
>
> **Boa prática:** manter os OKR como uma ferramenta de alinhamento e direção coletiva, separada de qualquer avaliação individual; uma meta ambiciosa alcançada em 70% continua sendo um sinal positivo, não um fracasso.

## 📋 Recapitulação

| | |
|---|---|
| **A lembrar** | Um OKR combina uma meta qualitativa e ambiciosa (Objective) com de 2 a 5 resultados mensuráveis que provam seu alcance (Key Results). As user stories do backlog contribuem concretamente para um Key Result, sem que o OKR desça ao nível do detalhe de implementação. Uma taxa de alcance em torno de 60-70% é saudável, não um fracasso. |
| **Ferramentas utilizáveis** | O formato Objective + Key Results (de 2 a 5 por objetivo) para conectar o trabalho diário e a direção coletiva. |
| **Ciladas a evitar** | Confundir um Key Result com uma tarefa a fazer. Usar a taxa de alcance como medida de desempenho individual. |
| **Boas práticas** | Formular cada Key Result como uma medida verificável, nunca como uma ação a marcar. Manter os OKR separados de qualquer avaliação individual. |
