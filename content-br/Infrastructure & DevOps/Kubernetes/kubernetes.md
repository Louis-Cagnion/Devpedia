# Kubernetes

O [Docker](/?c=infrastructure-devops&s=docker&p=docker) sabe fazer rodar um contêiner; o Kubernetes sabe fazer rodar **toda uma frota** de contêineres enquanto máquinas falham, o tráfego varia e novas versões são entregues continuamente. Descreve-se o que se quer ver rodando, e o Kubernetes faz a realidade corresponder a essa descrição, continuamente.
