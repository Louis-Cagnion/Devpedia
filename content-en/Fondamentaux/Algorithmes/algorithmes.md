# Algorithmes

This part covers analyzing an algorithm independently of its implementation: how to estimate its cost in time and memory (Big-O notation), and how to compare several ways of solving the same problem (sorting algorithms as a textbook case). It's distinct from [Performance](/?c=performance), which optimizes an algorithm that's already been chosen (memory access, allocations, parallelism) rather than comparing intrinsic complexity.
