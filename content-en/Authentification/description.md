# Description

This category covers authentication end to end, independently of the language or framework used: how to prove your identity (**Fundamentals**: passwords, authentication factors), how a server remembers that a user is logged in from one HTTP request to the next (**Sessions and Tokens**: cookies, JWT), how to delegate that identity to a third party instead of managing it yourself (**Delegation and Identity Federation**: OAuth 2.0, OpenID Connect, SSO with Okta as a concrete example), and how to reduce the risk of a single secret compromising an entire account (**Strengthening Authentication**: multi-factor authentication).
