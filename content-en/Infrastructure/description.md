# Description

This category starts from zero: no prior knowledge is assumed about how programs communicate with each other or how a computation actually runs on hardware. It lays out the vocabulary (API, HTTP, JSON, CPU, GPU, cloud) that the artificial intelligence chapters need, so every infrastructure notion they use can be understood without taking anything for granted.

If a chapter elsewhere on Devpedia uses an infrastructure term without redefining it, it generally points to one of the chapters below.
