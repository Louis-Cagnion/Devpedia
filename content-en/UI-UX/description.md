# Description

This category covers user interface (UI) and user experience (UX) design: how a page or application communicates visually, guides attention, and stays usable by anyone. It starts from basic visual principles (hierarchy, color, typography, spacing) before moving on to design methods (user research, prototyping, design systems).

The site's HTML/CSS chapters cover "how to code" an interface; these cover the "why" and "what to design" upstream; each redirects to the other where relevant.
