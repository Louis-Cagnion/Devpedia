# Home

Welcome to **Devpedia**, a knowledge base that explains software development from the ground up: each concept starts with a simple definition, a concrete example, and then the “why”, without ever assuming the reader knows any terms that haven’t been explained first.

## Where to start?

| Your situation | Starting point |
|---|---|
| You've never used a terminal or written a line of code | [Computer Science Basics](/?c=bases-de-l-informatique&p=code-programmes-et-fichiers): the foundation on which the rest of the site is built |
| You already know how to code and are looking for a specific language or topic | The navigation bar (on the left, or at the top on mobile) and the search function list all categories |

## What this site covers

- Programming languages: C, C++, PHP, Python, JavaScript, OCaml
- Markup languages and user interface: HTML, CSS, UI/UX
- Command line and version control: Bash, PowerShell, Zsh, Git
- Infrastructure, databases (SQL), Docker
- Data Science and Artificial Intelligence
- Mathematics, data representation, performance, code quality, and architecture

When a chapter refers to a concept that has already been explained elsewhere on the site, it provides a link to that section rather than repeating the information; follow these links whenever you come across a term you’re not familiar with.
