# Bases de données

This section covers how data is organized once you go beyond the single table seen in [SQL](/?c=domain-specific-languages-dsl&p=sql): how to structure multiple tables together to analyze large volumes of history (reporting, dashboards) rather than to run a day-to-day application, and the vocabulary of tables you encounter in a real data warehouse.

It's distinct from [Data Science](/?c=data-science): the latter covers the tools for working with data that's already available ([pandas](/?c=data-science&p=pandas), [NumPy](/?c=data-science&p=numpy)...), while this one covers how that data is structured and organized upstream.
