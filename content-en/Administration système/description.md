# Description

This category covers administering a Linux server: installing and choosing a distribution, organizing its storage, controlling access beyond classic permissions, hardening remote access and privileges, and filtering incoming network traffic. It builds on [Permissions and File Manipulation](/?c=shells&s=bash&p=permissions-et-fichiers), which covers basic permissions (users, groups, `chmod`), by tackling the security of a whole system this time rather than a single file.
