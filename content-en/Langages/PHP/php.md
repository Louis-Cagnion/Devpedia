# PHP

A [programming language](/?c=bases-de-l-informatique&p=code-programmes-et-fichiers) is a set of rules that lets you write instructions a computer can execute. PHP is one such language, designed specifically to run on a web server and generate pages on demand.

```php
<?php
$name = "Devpedia";     // a variable, see the dedicated chapter
echo "Hello, $name";    // displays: Hello, Devpedia
```

| Term | What it means |
|---|---|
| High-level | Hides most of the technical details tied to the machine, unlike a low-level language such as [C](/?c=langages-de-programmation&s=c&p=c) |
| Garbage collector | As in [JavaScript](/?c=langages-de-programmation&s=javascript&p=javascript), the memory of values that are no longer used is freed automatically |
| HTTP request | The message a browser sends to a server to request a page (see [Data exchange: API and HTTP](/?c=infrastructure&p=api-et-http)). PHP runs server-side, precisely to respond to these requests |

Learning PHP helps you understand how a web server processes a request and interacts with a database (see [SQL](/?c=domain-specific-languages-dsl&p=sql)) to generate a response. It remains widely used for dynamic websites, CMSs ([WordPress](https://wordpress.org), [Drupal](https://www.drupal.org)), and frameworks such as [Laravel](https://laravel.com) or [Symfony](https://symfony.com).
