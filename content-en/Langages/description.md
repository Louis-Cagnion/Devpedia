# Description

This section covers the site's different languages, each with its own syntax: general-purpose programming languages (**[C](/?c=langages&s=c&p=c)**, **[C++](/?c=langages&s=cpp&p=cpp)**, **[PHP](/?c=langages&s=php&p=php)**, **[Python](/?c=langages&s=python&p=python)**, **[JavaScript](/?c=langages&s=javascript&p=javascript)**, **[OCaml](/?c=langages&s=ocaml&p=ocaml)**), markup languages that describe a web page rather than a behavior (**[HTML](/?c=langages&s=html&p=html)**, **[CSS](/?c=langages&s=css&p=css)**), shell command languages (**[Bash](/?c=langages&s=bash&p=bash)**, **[Zsh](/?c=langages&s=zsh&p=zsh)**, **[PowerShell](/?c=langages&s=powershell&p=powershell)**), and special-purpose languages designed for one specific problem rather than to do everything (**[Domain-specific Languages (DSL)](/?c=langages&s=domain-specific-languages-dsl&p=domain-specific-languages-dsl)**, e.g. [SQL](/?c=langages&s=domain-specific-languages-dsl&p=sql), [regex](/?c=langages&s=domain-specific-languages-dsl&p=regex)).
