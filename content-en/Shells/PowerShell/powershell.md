# PowerShell

PowerShell is Windows's default shell, also available on Linux and macOS since its *PowerShell Core* version (cross-platform, often invoked via `pwsh`). Its fundamental difference from Bash: in a pipe or a variable, Bash only handles **text**, whereas PowerShell passes around actual **.NET objects** — a command can thus access a property directly (`.Name`) without having to extract a text column.
