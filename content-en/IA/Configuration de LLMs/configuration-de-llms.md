# Configuration de LLMs

This part covers how to customize and automate the behavior of an LLM or an LLM agent, once you already know what an agent is ([tool/reasoning loop](/?c=ia&s=nlp-llm&p=agents)) and what a product built around one looks like ([agent-based AI assistant in the terminal](/?c=ia&s=applications-llm&p=assistant-agentique-terminal)): how to make it react reliably at a precise moment in its operation, without relying solely on a prompt instruction.
