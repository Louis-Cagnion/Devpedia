# Fundamentals of Deep Learning

This part covers the building blocks shared by every **deep learning** model, before it gets specialized for a specific task (text, image, character recognition...): how a neuron computes, how a network learns from data, and the major families of architectures that organize these neurons (CNNs, RNNs, Transformers).

The other topics in this category ([NLP and LLM](/?c=ia&p=nlp-llm), [Vision and OCR](/?c=ia&p=vision-et-ocr)...) all build on these notions rather than redefining them: this is the natural starting point for approaching modern AI with no prior background.
