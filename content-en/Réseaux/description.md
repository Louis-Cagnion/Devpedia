# Description

This category covers how a computer network works, from addressing a machine to communication between programs via sockets. It sits below the application level already covered elsewhere (e.g. [Exchanging Data: API and HTTP](/?c=infrastructure&p=api-et-http), which assumes a network connection already exists): here, we explain how that connection comes to exist in the first place, from the cable all the way up to the program.
