# Description

Cette catégorie part de zéro : aucune connaissance préalable n'est supposée, pas même savoir ce qu'est un terminal ou un éditeur de code. Elle pose le vocabulaire et les notions dont tout le reste du site a besoin (fichier, programme, code, terminal, IDE, arborescence...) pour que chaque autre chapitre du site puisse s'appuyer sur elles sans les réexpliquer.

Si un chapitre ailleurs sur Devpédia utilise un terme sans le redéfinir, il pointe généralement vers l'un des chapitres ci-dessous.
