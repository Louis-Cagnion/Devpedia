# Description

Cette section couvre les différents langages du site, chacun avec sa propre syntaxe : les langages de programmation généralistes (**C**, **C++**, **PHP**, **Python**, **JavaScript**, **OCaml**), les langages de balisage qui décrivent une page web plutôt qu'un comportement (**HTML**, **CSS**), les langages de commande d'un terminal (**Bash**, **Zsh**, **PowerShell**), et les langages à usage spécifique conçus pour un problème précis plutôt que pour tout faire (**Domain-specific Languages (DSL)**, ex. SQL, regex).
