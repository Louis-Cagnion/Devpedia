# Description

Cette section couvre les différents langages du site, chacun avec sa propre syntaxe : les langages de programmation généralistes (**[C](/?c=langages&s=c&p=c)**, **[C++](/?c=langages&s=cpp&p=cpp)**, **[PHP](/?c=langages&s=php&p=php)**, **[Python](/?c=langages&s=python&p=python)**, **[JavaScript](/?c=langages&s=javascript&p=javascript)**, **[OCaml](/?c=langages&s=ocaml&p=ocaml)**), les langages de balisage qui décrivent une page web plutôt qu'un comportement (**[HTML](/?c=langages&s=html&p=html)**, **[CSS](/?c=langages&s=css&p=css)**), les langages de commande d'un terminal (**[Bash](/?c=langages&s=bash&p=bash)**, **[Zsh](/?c=langages&s=zsh&p=zsh)**, **[PowerShell](/?c=langages&s=powershell&p=powershell)**), et les langages à usage spécifique conçus pour un problème précis plutôt que pour tout faire (**[Domain-specific Languages (DSL)](/?c=langages&s=domain-specific-languages-dsl&p=domain-specific-languages-dsl)**, ex. [SQL](/?c=langages&s=domain-specific-languages-dsl&p=sql), [regex](/?c=langages&s=domain-specific-languages-dsl&p=regex)).
