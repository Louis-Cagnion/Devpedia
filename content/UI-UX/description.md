# Description

Cette catégorie couvre le design d'interface (UI) et d'expérience utilisateur (UX) : comment une page ou une application communique visuellement, guide l'attention et reste utilisable par n'importe qui. Elle part des principes visuels de base (hiérarchie, couleur, typographie, espacement) avant d'aborder les méthodes de conception (recherche utilisateur, prototypage, design systems).

Les chapitres [HTML](/?c=langages&s=html&p=html)/[CSS](/?c=langages&s=css&p=css) du site couvrent le "comment coder" une interface ; ceux-ci couvrent le "pourquoi" et le "quoi concevoir" en amont ; chacun redirige vers l'autre là où c'est pertinent.
