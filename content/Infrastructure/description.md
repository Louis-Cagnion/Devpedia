# Description

Cette catégorie part de zéro : aucune connaissance préalable n'est supposée sur la façon dont des programmes communiquent entre eux ou dont un calcul s'exécute matériellement. Elle pose le vocabulaire (API, HTTP, JSON, CPU, GPU, cloud) dont les chapitres d'intelligence artificielle ont besoin, pour que chaque notion d'infrastructure qu'ils utilisent puisse être comprise sans admettre quoi que ce soit sans explication.

Si un chapitre ailleurs sur Devpédia utilise un terme d'infrastructure sans le redéfinir, il pointe généralement vers l'un des chapitres ci-dessous.
