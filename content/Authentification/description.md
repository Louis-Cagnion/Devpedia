# Description

Cette catégorie couvre l'authentification de bout en bout, indépendamment du langage ou du framework utilisé : comment prouver son identité (**Fondamentaux** : mots de passe, facteurs d'authentification), comment un serveur se souvient qu'un utilisateur est connecté d'une requête HTTP à l'autre (**Sessions et tokens** : cookies, JWT), comment déléguer cette identité à un tiers plutôt que la gérer soi-même (**Délégation et fédération d'identité** : OAuth 2.0, OpenID Connect, SSO avec Okta comme exemple concret), et comment réduire le risque qu'un seul secret compromette tout un compte (**Renforcer l'authentification** : authentification multifacteur).
