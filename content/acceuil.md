# Accueil

Bienvenue sur **Devpedia**, une base de connaissances qui explique le développement en partant de zéro : chaque notion part d'une définition simple, un exemple concret, puis le "pourquoi", sans jamais présupposer un terme non expliqué au préalable.

## Par où commencer ?

| Votre situation | Point de départ |
|---|---|
| Vous n'avez jamais utilisé un terminal ni écrit une ligne de code | [Bases de l'informatique](/?c=bases-de-l-informatique&p=code-programmes-et-fichiers) : le socle sur lequel s'appuie tout le reste du site |
| Vous savez déjà coder et cherchez un langage ou un sujet précis | La barre de navigation (à gauche, ou en haut sur mobile) et la recherche listent toutes les catégories |

## Ce que couvre le site

- Langages de programmation : C, C++, PHP, Python, JavaScript, OCaml
- Langages de balisage et interface : HTML, CSS, UI/UX
- Ligne de commande et versioning : Bash, PowerShell, Zsh, Git
- Infrastructure, bases de données (SQL), Docker
- Data Science et Intelligence Artificielle
- Mathématiques, représentation des données, performance, qualité et architecture du code

Quand un chapitre a besoin d'une notion déjà expliquée ailleurs sur le site, il y renvoie par un lien plutôt que de la répéter ; suivez ces liens dès qu'un mot ne vous est pas familier.
