# Description

Cette catégorie couvre la blockchain : comment un réseau d'ordinateurs qui ne se font pas confiance entre eux peut quand même se mettre d'accord sur un historique commun, sans banque ni serveur central pour arbitrer. Elle part des concepts fondamentaux (bloc, hash, consensus, smart contract) avant d'aborder les langages et réseaux utilisés pour construire dessus.
