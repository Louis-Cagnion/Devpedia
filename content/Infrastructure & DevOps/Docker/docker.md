# Docker

Docker permet d'emballer une application avec tout son environnement d'exécution (bibliothèques, dépendances, configuration) dans une unité isolée et portable, le **conteneur** : ce qui fonctionne sur une machine fonctionne à l'identique sur une autre, sans le classique "ça marche chez moi".
