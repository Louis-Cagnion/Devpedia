# Description

Pour rappel, [le terminal affiche et transmet ce que vous tapez, le shell l'interprète et l'exécute réellement](/?c=bases-de-l-informatique&p=le-terminal). Plusieurs shells existent selon le système et l'usage : [Bash](/?c=shells&s=bash&p=bash) domine sur Linux/macOS, [PowerShell](/?c=shells&s=powershell&p=powershell) sur Windows (et au-delà, il tourne aussi sur Linux/macOS depuis [PowerShell](/?c=shells&s=powershell&p=powershell) Core).
