# Description

Un shell est un interpréteur de commandes : il lit ce que vous tapez dans un terminal, l'interprète, et l'exécute. Plusieurs shells existent selon le système et l'usage — Bash domine sur Linux/macOS, PowerShell sur Windows (et au-delà, il tourne aussi sur Linux/macOS depuis PowerShell Core).
