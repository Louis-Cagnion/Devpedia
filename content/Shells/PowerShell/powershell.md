# PowerShell

PowerShell est le shell par défaut de Windows, aussi disponible sur Linux et macOS depuis sa version *PowerShell Core* (multiplateforme, souvent invoquée via `pwsh`). Sa différence fondamentale avec [Bash](/?c=shells&s=bash&p=bash) : dans un pipe ou une variable, [Bash](/?c=shells&s=bash&p=bash) ne manipule que du **texte**, alors que PowerShell fait circuler de véritables **[objets .NET](https://learn.microsoft.com/en-us/dotnet/)** : une commande peut ainsi accéder directement à une propriété (`.Name`) sans avoir à extraire une colonne de texte.
