# Description

Cette catégorie couvre les tests logiciels : comment vérifier qu'un programme fait bien ce qu'il est censé faire, avant qu'un utilisateur ne le découvre à sa place. Elle part du vocabulaire normalisé de la discipline avant d'aborder les différents types de tests, leur organisation, et les outils qui les rendent maintenables.

Le chapitre [tests et audit de sécurité](/?c=securite&s=cybersecurite&p=tests-et-audit-de-securite) couvre la recherche de failles de sécurité, un objectif différent de celui des tests couverts ici (vérifier que le programme fonctionne comme prévu).
