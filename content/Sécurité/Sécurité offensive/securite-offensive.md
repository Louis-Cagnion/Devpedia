# Sécurité offensive

[Cybersécurité](/?c=cybersecurite) couvre les failles applicatives et web, et comment s'en protéger. Cette catégorie change d'angle : comprendre comment un système est réellement attaqué au niveau le plus bas (mémoire, binaire, système d'exploitation), pour former le regard d'un attaquant plutôt que celui d'un défenseur. Les deux se complètent : on protège mieux ce qu'on sait attaquer.

> **Cadre légal :** tout ce qui suit ne s'applique que dans un environnement autorisé (challenge de type [CTF](/?c=securite&s=securite-offensive&p=ctf-capture-the-flag), machine de laboratoire dédiée, système que vous possédez ou pour lequel vous avez un mandat écrit). Le même rappel déjà posé pour le [pentest](/?c=cybersecurite&p=tests-et-audit-de-securite) s'applique ici : sans autorisation explicite, la même action devient illégale, même sans intention de nuire.
