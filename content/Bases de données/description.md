# Description

Cette section couvre la façon dont on organise les données une fois qu'on dépasse la table unique vue en [SQL](/?c=domain-specific-languages-dsl&p=sql) : comment structurer plusieurs tables entre elles pour analyser de grands volumes d'historique (reporting, tableaux de bord) plutôt que pour faire tourner une application au quotidien, et le vocabulaire des tables qu'on rencontre dans un entrepôt de données réel.

Elle se distingue de [Data Science](/?c=data-science) : cette dernière couvre les outils pour exploiter des données déjà disponibles (pandas, NumPy...), celle-ci couvre comment ces données sont structurées et organisées en amont.
