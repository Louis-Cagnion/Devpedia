# Description

Cette catégorie couvre le fonctionnement d'un réseau informatique, de l'adressage d'une machine jusqu'à la communication entre programmes via des sockets. Elle se place en dessous du niveau applicatif déjà couvert ailleurs (ex : [Les échanges de données : API et HTTP](/?c=infrastructure&p=api-et-http), qui suppose une connexion réseau déjà établie) : ici, on explique comment cette connexion existe et se construit, du câble jusqu'au programme.
