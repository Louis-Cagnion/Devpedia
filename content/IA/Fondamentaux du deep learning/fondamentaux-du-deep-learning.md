# Fondamentaux du deep learning

Cette partie couvre les briques communes à tout modèle de **deep learning**, avant qu'il ne soit spécialisé pour une tâche précise (texte, image, reconnaissance de caractères...) : comment un neurone calcule, comment un réseau apprend à partir de données, et les grandes familles d'architectures qui organisent ces neurones (CNN, RNN, Transformers).

Les autres subjects de cette catégorie ([NLP et LLM](/?c=ia&s=nlp-llm&p=nlp-llm), [Vision et OCR](/?c=ia&s=vision-et-ocr&p=vision-et-ocr)...) partent tous de ces notions plutôt que de les redéfinir : c'est le point de départ naturel pour aborder l'IA moderne sans base préalable.
