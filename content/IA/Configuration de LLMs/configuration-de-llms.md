# Configuration de LLMs

Cette partie couvre la façon de personnaliser et d'automatiser le comportement d'un LLM ou d'un agent LLM, une fois qu'on sait déjà ce qu'est un agent ([boucle outil/réflexion](/?c=ia&s=nlp-llm&p=agents)) et à quoi ressemble un produit construit autour ([assistant agentique en terminal](/?c=ia&s=applications-llm&p=assistant-agentique-terminal)) : comment le faire réagir de façon fiable à un moment précis de son fonctionnement, sans dépendre uniquement d'une instruction dans le prompt.
