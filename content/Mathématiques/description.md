# Description

Cette catégorie part de zéro : aucune connaissance mathématique préalable n'est supposée, pas même le lycée. Elle pose le vocabulaire (fonction, vecteur, probabilité, logarithme, dérivée, gradient) dont les chapitres d'intelligence artificielle et de data science ont besoin, pour que chaque notion mathématique qu'ils utilisent puisse être comprise sans admettre quoi que ce soit sans explication.

Si un chapitre ailleurs sur Devpedia utilise un terme mathématique sans le redéfinir, il pointe généralement vers l'un des chapitres ci-dessous.
