# PHP

O PHP é considerado uma linguagem de programação de **alto nível**, uma vez que oculta grande parte dos detalhes técnicos relacionados com o hardware e a gestão da memória. Ao contrário das linguagens de **baixo nível**, como o C, que exigem que o programador gere manualmente a memória e os endereços, o PHP automatiza estes aspetos graças a um recolhedor de lixo (*garbage collector*), permitindo que o programador se concentre na lógica da aplicação.

Entre os conceitos essenciais utilizados em PHP, destacam-se, nomeadamente:

- As variáveis e a tipagem dinâmica
- As tabelas (indexadas e associativas)
- Programação orientada a objetos (classes, interfaces, herança)
- A interação com os pedidos HTTP (GET, POST, sessões, cookies)
- A ligação e a manipulação de bases de dados (através de PDO ou MySQLi)

A aprendizagem do PHP permite compreender melhor como um servidor web processa um pedido, gera uma resposta e interage com um cliente (navegador). Ajuda a visualizar como os dados circulam entre o cliente, o servidor e a base de dados, e como o código é interpretado durante a execução.

Graças à sua simplicidade e à sua integração nativa com a Web, o PHP é amplamente utilizado no desenvolvimento de sites dinâmicos, aplicações Web, sistemas de gestão de conteúdos (CMS) e APIs.

A aprendizagem do PHP constitui também uma excelente base para compreender o funcionamento das aplicações web do lado do servidor, uma vez que muitos frameworks (Laravel, Symfony) e CMS (WordPress, Drupal) se baseiam nesta linguagem.
